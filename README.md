# 紅海過乾地 Red Sea 3D 🌊

出埃及記 14 的 3D 聖經遊戲。後有追兵、前有大海——摩西向海伸杖,耶和華使水分開;
**帶著百姓走乾地過紅海,一個也不失落**。全隊上岸,水牆才合攏。永遠不會輸。

## 怎麼玩
- **A / D** 或 **← / →**:左右帶路(避開礁石、等等掉隊的人)
- 提示出現時 **Enter / 點按**:摩西向海伸杖(出14:21)
- **V**:視角(跟隨/高空/側望)・手機:◀ ▶ + ⛶ 全螢幕

## 開發
npm install → npm run dev;gen-voice.mjs 烤人聲;verify-redsea.mjs Playwright 驗收。
技術:Three.js 零相依可離線 PWA;**C1 formation.js 編隊地基**(零耦合可搬)+ water-kit 活水牆。
